# ASimpleShot

ASimpleShot 是独立的 macOS 菜单栏截图工具，支持区域截图、取色、标注、OCR、复制到剪贴板和 PNG / JPG 导出。

界面提供英文、简体中文和繁体中文，随 macOS 的应用语言设置切换。

## 运行与编译

需要 macOS 26.2 或更新版本。用 Xcode 打开 `Screenshot.xcodeproj`，选择 `Screenshot` Scheme 并运行。菜单栏的取景框图标提供截图和设置入口。

在 Apple Silicon Mac 上也可以使用 Command Line Tools 编译。从 `Screenshot/` 目录执行：

```bash
python3 ../scripts/build_macos.py --app Screenshot
```

产物为仓库内的 `Screenshot/build/ASimpleShot.app`，固定签名版的 Bundle ID 为 `top.yayalu.Screenshot`。可使用仓库根目录已有的固定证书配置，也可以单独绑定证书：

```bash
python3 ../scripts/build_macos.py --app Screenshot --configure-signing "PasteHub Local Signing"
```

MozJPEG 4.1.5 随项目提供，由 Xcode 或构建脚本编译并静态链接。命令行构建缓存位于 `build/MozJPEG/`，应用分发包含 `ThirdPartyNotices.txt`。

## 截图与取色

- 按 `Option + Shift + A` 或菜单栏「截图 / 取色」开始，按 `Esc` 取消。
- 移动十字指针查看 180 × 180、3 倍放大的放大镜、当前屏幕的物理像素坐标和色值；按 `Shift` 切换 HEX / RGB，按 `Command + C` 复制色值并退出。
- 拖动鼠标左键框选区域；未选择标注工具时可移动选区，拖动八个控制点调整大小，选区外重新拖动可重新框选。
- 选区下方工具栏支持矩形、椭圆、画笔、直线、箭头、马赛克、纯色涂抹、文字（T）；绘图工具提供四档线宽与七种颜色。再次点击当前工具可退出标注模式。
- 马赛克和纯色涂抹沿鼠标轨迹覆盖，支持单击涂点；马赛克默认直径 12，可选 9 / 12 / 18 / 24；纯色涂抹默认直径 13，可选 9 / 13 / 17 / 21，鼠标处显示笔刷范围。纯色涂抹默认黑色，二级工具栏提供七色色板。撤销按钮或 `Command + Z` 撤销最近一笔标注。
- 选择 T 或按 `T` 后点击选区输入文字，使用系统字体，提供 12 / 18 / 24 / 32 / 48 五档字号（默认 24）及七种颜色；输入时可调整样式，`Enter` 完成、`Shift + Enter` 换行、`Esc` 取消本次编辑，点击已有文字可继续编辑。文字编辑期间支持原生复制、粘贴、撤销和中文输入法。矩形、椭圆、画笔、直线、箭头共用线宽，并与文字共用选色；马赛克与纯色涂抹分别记忆笔刷大小，纯色涂抹单独记忆颜色。以上配置及文字字号均持久化，重启后保留。
- 标注工具栏的质量图标以图片内部线条从完整到破碎区分无损、高、普通，自定义使用高档图片底图叠加画笔；点击展开预设、格式、缩放、质量四行设置。未保存档位时默认使用高档。无损为 PNG / 100% 尺寸 / 100% 质量，高为 JPG / 100% 尺寸 / 84% 质量，普通为 JPG / 75% 尺寸 / 78% 质量；预设锁定格式、缩放和质量，质量滑块灰显。自定义初始为 JPG / 100% 尺寸 / 75% 质量，可调整 PNG / JPG 格式及 20–100% 尺寸，JPG 质量可调 65–95%；PNG 质量始终显示 100% 并禁用。档位及全部自定义参数持久化，已有自定义 JPG 质量限制在 65–95%，切换格式或预设不会覆盖已保存的自定义 JPG 质量。
- 「设置 → 截图导出」提供全局「MozJPEG 压缩」开关，默认开启并持久化；关闭后使用系统 JPG 编码器。两种编码器均使用截图工具栏的 JPG 质量值，直接从截图像素编码一次。MozJPEG 采用 4:4:4 色度采样、渐进式编码及默认 Trellis 优化。
- 下载按钮按当前参数选择目录保存 PNG 或 JPG；取消保存返回编辑。未选择标注工具时双击已选截图区域、点击确认按钮、按 `Enter` 或框选后的 `Command + C` 将图片复制到系统剪贴板并退出截图。复制与保存均先缩放、再编码，JPG 仅执行一次有损编码；剪贴板同时提供原始 PNG / JPG 和兼容图片数据。
- 框选和拖动时，选区尺寸标签始终跟随选区，优先对齐左上角。「文字识别」和灰色禁用的「滚动截图」使用独立的深灰色按钮，拖动开始时立即隐藏，选区稳定 0.75 秒后以 0.3 秒淡入。按钮优先在选区顶部居中，空间不足时依次尝试右侧居中竖排、左侧居中竖排、底部靠左，全屏选区内显示。点击「文字识别」后，在原选区内再次框选需要识别的区域，使用系统 Vision 在本机提取文字。结果框优先放在截图外，空间不足时放在截图内，使用高斯模糊背景；文本支持编辑、滚动和选择复制，底部“复制”复制当前全文，“关闭”返回截图编辑。识别期间显示加载指示；失败显示红色警告图标，超过 10 秒显示橙色超时图标，3 秒后恢复二次框选。`Esc` 先退出识别，编辑选区、标注或退出截图会取消当前识别。
- 当前支持在任意一个显示器内截图；滚动截图与跨屏框选见 [实现列表](docs/screenshot-todo.md)。

## 设置与迁移

- 「快捷键」可录制截图 / 取色组合，默认 `Option + Shift + A`。
- 「截图导出」控制 JPG 是否使用 MozJPEG。
- 「权限」显示截图授权状态，并提供系统设置入口。
- 首次启动时从旧版 PasteHub 导入截图快捷键、MozJPEG、标注工具和质量预设等截图偏好。导入支持 `top.yayalu.PasteHub` 和 `com.example.PasteHub`，优先保留 ASimpleShot 已有设置。此后在 ASimpleShot 的偏好域中独立保存。

## 截图权限

第一次使用截图或取色时，前往「系统设置 → 隐私与安全 → 录屏与系统录音」为 ASimpleShot 单独授权。授权后若仍无法截图，请退出并重新打开 ASimpleShot。截图无需辅助功能或输入监控权限，也不采集音频。
