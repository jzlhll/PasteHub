# 截图功能实现列表

## 本期

- [x] 默认 `Option + Shift + A` 开始截图；支持设置自定义快捷键和菜单栏入口。
- [x] `Esc` 或关闭按钮取消截图；重复触发不创建并行会话。
- [x] 冻结各显示器画面；一次选区限定在单个显示器内，按原始像素清晰度导出。
- [x] 十字指针；指针左下方展示 180 × 180、3 倍放大的画面，左侧不足时置于右下方，底部不足时避让屏幕边界。
- [x] 放大镜下显示当前显示器内以左上角为原点的物理像素坐标及小写 HEX 色值。
- [x] 取色阶段每按一次 `Shift` 切换 HEX / RGB；`Command + C` 复制当前色值并退出，提示复制内容。RGB 格式为 `(110, 100, 100)`。
- [x] 鼠标左键拖动框选；选区保持原亮度，其他区域增加暗色蒙层。
- [x] 支持移动选区和八个方向调整选区；选区外重新拖动可重新框选。
- [x] 工具栏与画布隔离鼠标按下事件；禁用按钮、工具栏空白及选区外单击不创建单点选区。
- [x] 新选区在宽、高均超过 10 个物理像素且松开鼠标后生效；无效拖动保留原选区与标注，缩放和导出使用相同的最小尺寸限制。
- [x] 矩形、椭圆、画笔、直线、箭头；五种工具共用 3 / 6 / 9 三档线宽，以及红、黄、绿、蓝、黑、灰、白七色。
- [x] 马赛克与纯色涂抹：沿鼠标轨迹覆盖，支持单击涂点；共用 24 / 36 / 48 三档粗笔刷，默认直径 36，并显示笔刷范围。纯色涂抹默认黑色，二级工具栏提供七色色板和当前 HEX 色值。
- [x] 撤销标注及 `Command + Z`。
- [x] 下载按钮通过系统保存窗口选择目录和文件名，保存为 PNG；取消保存返回编辑。
- [x] 确认按钮或 `Enter` 复制截图至系统剪贴板并退出；框选完成后 `Command + C` 同样复制截图。
- [x] 屏幕录制权限检查、首次请求、拒绝说明、设置入口和状态刷新；无需为截图另加辅助功能、输入监控、音频录制权限。
- [x] 捕获失败、写入剪贴板或保存失败提示；显示器参数变化时取消截图，清理异步任务和窗口。
