# 截图功能实现列表

## 本期

- [x] 默认 `Option + Shift + A` 开始截图；支持设置自定义快捷键和菜单栏入口。
- [x] `Esc` 或关闭按钮取消截图；重复触发不创建并行会话。
- [x] 冻结各显示器画面；一次选区限定在单个显示器内，按原始像素清晰度导出。
- [x] 十字指针；指针左下方展示 180 × 180、3 倍放大的画面，左侧不足时置于右下方，底部不足时避让屏幕边界。
- [x] 放大镜下显示当前显示器内以左上角为原点的物理像素坐标及小写 HEX 色值。
- [x] 取色阶段每按一次 `Shift` 切换 HEX / RGB；`Command + C` 复制当前色值并退出，提示复制内容。RGB 格式为 `(110, 100, 100)`。
- [x] 鼠标左键拖动框选；选区保持原亮度，其他区域增加暗色蒙层。
- [x] 支持移动选区和八个方向调整选区；选区外重新拖动可重新框选。
- [x] 工具栏与画布隔离鼠标按下事件；禁用按钮、工具栏空白及选区外单击不创建单点选区。
- [x] 新选区在宽、高均超过 10 个物理像素且松开鼠标后生效；无效拖动保留原选区与标注，缩放和导出使用相同的最小尺寸限制。
- [x] 矩形、椭圆、画笔、直线、箭头；五种工具均提供 2 / 4 / 6 三档线宽，以及红、黄、绿、蓝、黑、灰、白七色。
- [x] 马赛克与纯色涂抹：沿鼠标轨迹覆盖，支持单击涂点；均提供 9 / 15 / 21 三档粗笔刷，默认直径 15，并显示笔刷范围。纯色涂抹默认黑色，二级工具栏提供七色色板。
- [x] `T` 添加文字：系统字体，14 / 18 / 24 / 32 / 48 五档字号及七种颜色，支持中文输入、多行文字和再次编辑；预览与导出共用 TextKit 排版。
- [x] 绘图工具共用线宽，并与文字共用颜色；马赛克和纯色涂抹共用笔刷大小，纯色涂抹颜色独立；这些配置与文字字号均持久化；每次截图仍从框选开始。
- [x] 撤销标注及 `Command + Z`。
- [x] OCR 旁的质量图标展开二级工具栏；高（PNG / 100% / 100%）、中（JPG / 100% / 82%）、低（JPG / 75% / 75%）锁定参数，自定义开放格式、尺寸及 JPG 质量，PNG 质量固定 100%。档位与自定义参数持久化，PNG 不覆盖已保存的 JPG 质量。
- [x] 下载按钮通过系统保存窗口选择目录和文件名，按当前参数保存 PNG / JPG；取消保存返回编辑。复制与保存共用先缩放、后编码的流程，历史缓存及重新复制保留原始编码数据。
- [x] 确认按钮或 `Enter` 复制截图至系统剪贴板并退出；框选完成后 `Command + C` 同样复制截图。
- [x] 选区工具栏进入二次框选，在原截图内通过 Vision 本机识别文字；结果框优先放在截图外，放不下时放在截图内，使用高斯模糊背景、可编辑文本框及“复制”“关闭”按钮。识别失败或 10 秒超时在工具栏按钮上显示图标，3 秒后恢复二次框选；`Esc` 返回截图编辑，编辑选区、标注或退出时取消识别。
- [x] 屏幕录制权限检查、首次请求、拒绝说明、设置入口和状态刷新；无需为截图另加辅助功能、输入监控、音频录制权限。
- [x] 捕获失败、写入剪贴板或保存失败提示；显示器参数变化时取消截图，清理异步任务和窗口。
