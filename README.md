# PasteHub

本仓库包含两个独立的 macOS 菜单栏应用，以及图片工具和跨平台编解码库。

| 项目 | 功能 |
| --- | --- |
| [PasteHub/README.md](PasteHub/README.md) | 剪贴板历史、常用片段、搜索和自动回填 |
| [Screenshot/README.md](Screenshot/README.md) | ASimpleShot，提供区域截图、取色、标注、文字识别和导出 |
| [cli/README.md](cli/README.md) | 图片处理命令行工具 |
| [image-library/README.md](image-library/README.md) | 跨平台图片编解码库，包含独立的 Android AAR 工程 |
